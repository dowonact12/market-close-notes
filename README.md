# 마감 노트

국장·미장 일반 신호 및 드래곤볼 후보를 비교하는 모바일 대응 공개 요약 사이트입니다.

- `index.html`: 화면, 분류·검색·상태 필터, 종목별 상세, 분석 이력 선택.
- `reports.json`: 관측일을 포함한 공개용 분석 요약. 첫 항목이 최신 분석입니다.
- GitHub Pages의 `main` 브랜치 루트에서 배포합니다. 빌드나 API 키가 필요하지 않습니다.

정적 사이트는 게시된 결과를 보여 줍니다. 분석은 별도의 로컬 예약 작업에서 수행하며 PC·앱·로그인된 브라우저가 실행 가능한 상태여야 합니다. 예약 등록과 무인 실행 성공은 구분합니다.

강의 원문, 비공개 채널 원문, 차트 계정 화면, 계좌 정보, 인증값은 저장소에 올리지 않습니다. 원자료의 오류나 접근 실패를 새 분석으로 대체하지 않습니다. 공개 내용은 분석자가 작성한 후보 요약이며 주문 기능이 없습니다.
